# Sync Skills — Custom Python Script Skill

This skill allows the agent to run the helper python script `sync_skills.py` to automate the analysis and syncing of custom skills.

## Instructions

Run the Python script:
`python3 .agents/skills/sync-skills/scripts/sync_skills.py`
