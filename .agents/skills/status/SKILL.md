# Status — Report current focus and sequence state.

## Instructions

1. Read `planning/STATUS.md`.
2. Report exactly:
   - **Current focus** line (verbatim).
   - What is **In progress** (from the progress table).
   - What is **Next** in the sequence.
3. Status values are title-case (`Not started · In progress · Done · Blocked · Skipped`) — read them as written.
4. Do not read any other file. Do not summarize the full plan.
